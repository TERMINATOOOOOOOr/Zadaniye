    API

    The same pipeline is available programmatically. The response is JSON only.

    curl -F "file=@video.mp4" {{ host }}/api/detect

    Response:

    {
  "job_id": "…", "state": "done", "video": "video.mp4", "duration": 60.0,
  "events": [[5.0, 8.0, "red_light"], [20.0, 26.0, "accident"]],
  "risk": [[0.0, 0.0], [0.08, 0.0], …],
  "timing_sec": {"part_a": 41.2, "part_b": 12.7},
  "notes": [], "events_url": "/jobs/…/events.json", "annotated_url": null
}

    Query parameters: risk=0 — skip Part B; annotate=1 — also render the video (link in annotated_url); wait=0 — return the job_id immediately and poll GET /api/jobs/{id} (fields state, progress, stage, result). Class list: GET /api/classes. The limits are the same as for the form; errors come back as {"detail": "…"} with status 400 / 413 / 503.
